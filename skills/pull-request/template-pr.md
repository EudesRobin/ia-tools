# Template de description de pull request

Template **indicatif**, employé quand le projet n'en déclare aucun : un point
de départ raisonnable, à adapter à la PR. Rédiger chaque section à partir des
commits et du diff de la branche ; ne recopier ni le diff ni la liste des
commits.

```markdown
## Contexte

<Le problème ou le besoin auquel répond la PR, en une à trois phrases.>

## Changements

- <Changement significatif, formulé du point de vue de l'utilisateur du projet.>
- <…>

## Vérification

- <Commande lancée ou parcours exercé, et résultat observé.>
```

La section « Vérification » ne mentionne que des contrôles effectivement
réalisés. Aucun contrôle réalisé → écrire « Aucun contrôle réalisé » plutôt que de
laisser la section vide.
